# 現場リンク（固定URL）— サーバー設置手順

外出先アクセスのトンネルURLは接続のたびに変わる。そのままでは職人さんに毎回LINEでURLを
送り直すことになるので、「会社ごとに変わらない入口」を1本立てて、そこから今生きている
URLへ転送する。職人さん側はこのアドレスをブックマークするだけでよくなる。

```
https://nakanokoumuten.com/genba/nakano  →  https://xxxx.trycloudflare.com
```

## 設置（エックスサーバー、1回だけ）

1. サーバーパネル → **ファイル管理**（またはFTP）
2. `nakanokoumuten.com/public_html/` の下に `genba` フォルダを作る
3. このフォルダの中身をアップロードする
   - `index.php`
   - `update.php`
   - `.htaccess`
   - `data/.htaccess`（`data` フォルダごと）
4. `data` フォルダの書き込み権限を **755**（不可なら 777）にする

以上。DNSの変更もサブドメイン作成も不要。

## 動作確認

```
https://nakanokoumuten.com/genba/test
→ 「まだ準備されていません」と出れば設置成功
```

アプリ側で 設定 →「外出先からアクセス」をONにすると、表示されている現場リンクが
その場で使えるようになる。

## 仕組みと安全性

- アプリはトンネルが張られるたび `update.php` に `{id, url, token}` をPOSTする
- **合言葉は使わない。** アプリは公開リポジトリからビルドされるので、埋め込んだ合言葉は
  必ず読まれる。代わりに「先に登録した端末がそのIDの持ち主」とし、初回のtokenを保存して
  2回目以降は同じtokenを出せた端末だけが上書きできるようにしている
- 転送先は `*.trycloudflare.com` / `*.loca.lt` **だけ**を受け付ける。万一tokenが漏れても
  任意の詐欺サイトへ飛ばすことはできない
- `data/` はWebから読めないようにしてある（tokenが入っているため）
- 6時間以上更新が無ければ転送せず「いまは接続できません」と表示する。
  事務所のPCが落ちているときに、死んだリンクへ飛ばして「壊れている」と思われるのを防ぐ

## ドメインを変えるとき

`app/src/main/main.ts` の `GENBA_BASE` を書き換えてリリースする。
（例: `https://kentiku-boost.jp/genba`）
